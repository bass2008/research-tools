# Свои проверки (исполнитель цикла, не агент)

## S1. В подписи диска пропала единица измерения

- **Что видит человек:** в панели состояния админки под плиткой «Диск» написано
  `занято 77.4 из 125.4 ГБ · свободно 48` — у второго числа нет единицы.
- **Когда возникает:** всегда, на всех ширинах (проверено 1360 и 390 px). У плитки «Том с базой»
  такой строки нет вовсе — там путь, поэтому там дефекта нет.
- **Почему не находили раньше:** подпись переписывалась в этом же цикле («занято X из Y» вместо
  «свободно X из Y»), тест на панель проверяет наличие слов «Диск», «Том с базой» и знака «%»,
  но не полноту подписи.
- **Достижимость:** обычный путь (админка).
- **Артефакт:** снимки `admin-top.png`, `admin-390.png` в каталоге прогона.

## Проверено и дефектов не найдено

- мобильный вид панели состояния (390 px): плитки в столбик, горизонтальной прокрутки нет
  (`scrollWidth == innerWidth == 390`);
- согласованность чека, формы банка и писем: чек — «Адаптация web-страницы: персональный расчёт
  матрицы судьбы по дате рождения», форма банка — «Матрица судьбы — персональный разбор по дате
  рождения», письма — «ваш разбор готов» / «Разбор закрыт, сохранённые даты остались в кабинете»;
- витрина тарифов: публичный только `single` (250 ₽), `month` скрыт — договор не обещает
  недоступного тарифа.

## Не проверяется на ступени 1 (перенесено в шаг 2)

- закрытие брошенных платежей (`ABANDONED`) — на моке платёж оплачивается мгновенно, брошенных
  не бывает; проверять на живом тестовом терминале;
- состав и наименование чека — мок чеков не выпускает.
