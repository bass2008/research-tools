## Общее для задач 02–05

Работаешь в `project/destiny-matrix/mobile/` (Expo 58, RN 0.88). Перед началом прочитай
`mobile/AGENTS.md`, `/home/sergey/Personal/research-tools/tools/mobile/task-01.md` (замысел и ограничения) и
`out/mobile-redesign/task-01.last.md` (что уже сделано). Прежняя версия — `out/mobile-astra-snapshot/`.

Цель всей переделки: приложение, которое хочется открывать каждый день и в котором хочется купить
полный разбор. Владелец оценивает только итог на телефоне. Не копия сайта: никаких хлебных крошек,
SEO-заголовков, шапки сайта, оговорок «это пример», «доступен без сети».

Цикл разработки: эмулятор `emulator-5554` запущен, dev-client установлен, Metro на 8081
(команды в `out/mobile-redesign/dev.json`). Если Metro или эмулятор упали — подними заново по
этим командам. Нативную зависимость ставь только через `npx expo install`, после неё пересобери
dev-client.

Ограничения: git — только чтение, ничего не публиковать. Локальный сервер на 3000/8018 можно
перезапускать. В `api/` и `web/` (импорт из `web/lib` можно) — только мелкий багфикс, без
которого задача не решается: без миграций, без денег и прав, без изменений, видимых на сайте;
после — тесты затронутой части. Каждую такую правку перечислить в последнем сообщении. Крупнее —
не делать, а описать в последнем сообщении. Не писать новых толкований арканов и позиций — только
существующие тексты проекта. У российских аккаунтов и неизвестной страны нет покупки и ссылок на
оплату. Платные подписи позиций (`spec/sections.json`) и платные тексты не попадают в бесплатную
часть. Новые подписи интерфейса — RU и EN. Комментарии — только на неочевидное, без докстрингов,
без однострочных компонентов на сотни символов.

Сдача каждой задачи: `npm run typecheck`, `npm run lint`, `npm test` проходят; скриншоты с
эмулятора (шрифт 100%, RU, если не сказано иначе) в `out/mobile-redesign/<задача>/`, после
снимков вернуть RU и шрифт 100%; последнее сообщение — коротко, что сделано и что нет.
