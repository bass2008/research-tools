# Задача 04: то, чего не умеет сайт

1. Карточка «поделиться» для темы дня и для моей матрицы: картинка 1080×1920 (карта колоды,
   название, вопрос дня или схема с датой, знак Arcana Sense), системное окно «Поделиться».
   Без персональных данных, кроме даты на карточке матрицы, и только по нажатию человека.
2. Виджет на рабочий стол Android: карта темы дня и её название, нажатие открывает «Сегодня».
   Обновление после полуночи по местному времени. Если выбрана «моя дата» — вторая строка
   «аркан месяца N · название». Библиотеку подбери под Expo 58 (config plugin, без ручной правки
   `android/`), пересобери dev-client.
3. Утреннее напоминание: по умолчанию выключено; включается на «Сегодня» одной строкой
   «Напоминать о теме дня в 9:00» и в настройках (время меняется). Локальное ежедневное
   уведомление, без сервера и без push-аккаунтов; текст — название темы дня; нажатие — «Сегодня».
   Просить разрешение только в момент включения.
4. Тактильный отклик: выбор точки (уже есть), открытие главы, успешная покупка.

Проверь виджет и уведомление на эмуляторе. Скриншоты в `out/mobile-redesign/task-04/`:
`share-daily`, `share-matrix`, `widget-home`, `notification`, `reminder-setting`.
