# Задача 02: один стиль и остальные экраны в новом виде

Образец вида — экраны «Сегодня» и «Матрица» из задачи 01 (`out/mobile-redesign/task-01/*.png`):
крупный заголовок Cormorant на фоне, без шапки, бумажные карточки, бирюза и золото.

1. Удалить пять оформлений: `state/Design.tsx` превратить в один модуль темы (токены «Ателье»),
   убрать все ветки `design.id`, экран `/appearance`, маршрут `/design`, пункт «Оформление» в
   настройках, сценарии Maestro и тесты переключателя, неиспользуемые варианты в
   `DesignElements`. Поведение остальных экранов не менять.
2. Убрать хлебные крошки на всех экранах (статьи, тема дня, галерея, разделы энциклопедии).
   Вложенные экраны: тонкая шапка со стрелкой назад и названием экрана, без логотипа, `RU` и
   шестерёнки. Язык — только в настройках.
3. «Сегодня»: строку «В вашей матрице эта карта — …» перенести внутрь карточки темы дня и
   сделать явной кнопкой-строкой (бирюза, стрелка); нажатие — «Матрица» с открытой шторкой точки.
4. «Пара»: первый партнёр подставлен из «моей даты»; экран ввода и результат — в новом виде.
5. «Год»: в новом виде, дата подставлена.
6. «Знания»: вместо нумерованного списка разделов — поиск сверху, горизонтальная лента 22 карт
   («Арканы», нажатие — статья), ниже разделы плитками с картинкой колоды. Блок «Всегда с вами
   … без интернета» убрать.
7. «Кабинет»: гость — одна карточка входа; вошедший — мои сохранённые разборы карточками со
   схемой-миниатюрой; шестерёнка настроек.
8. Настройки: Моя дата, Язык, Аккаунт, Поддержка, документы; блок локальной проверки остаётся
   только в локальной сборке.

Скриншоты в `out/mobile-redesign/task-02/`: `pair`, `pair-result`, `year`, `library`,
`library-search`, `article`, `daily-theme`, `account-guest`, `settings`, `today-top`.
