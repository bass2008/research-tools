# Аркан на месяц: числа из движка

Скрипт: `tools/seo/month-arcana/stats.py`, движок — `month_matrix(birth, year, month)` и
`year_matrix(birth, year)` из `project/destiny-matrix/engine/lisovskaya.py`.
SHA-256 модулей при расчёте: `lisovskaya.py` 1c86cb70c45e0203, `matrix.py` 130cb4c0e1125bcb.
Запуск: `/home/sergey/miniconda3/envs/research3.12/bin/python tools/seo/month-arcana/stats.py > tools/seo/month-arcana/stats.md`.
Население — все даты рождения с 01.01.1900 по 31.12.2025, месяцы — двенадцать месяцев 2026 года,
если не сказано иное. Буквы — как в движке: A день, B месяц, C год, D нижняя точка, E центр,
F = A + B, G = B + C, H = C + D, I = D + A.

## 1. Примеры расчёта

### Основной пример статьи

Дата рождения 19.01.1975, месяц — январь 2026.
- день месяца: сумма цифр 2026 = 10, плюс номер месяца 1 = 11; дата месяца 11.01.2026
- A = 11 + 19 = 30 → 3
- B = 1 + 1 = 2
- C = 1975 + 2026 = 4001 → 5
- D = A + B + C = 10
- E = A + B + C + D = 20 — **центр месяца, 20 · Суд**
- F = A + B = 5, G = B + C = 7, H = C + D = 15, I = D + A = 13

### Контроль

Дата рождения 07.10.1988, месяц — ноябрь 2026.
- день месяца: сумма цифр 2026 = 10, плюс номер месяца 11 = 21; дата месяца 21.11.2026
- A = 21 + 7 = 28 → 10
- B = 11 + 10 = 21
- C = 1988 + 2026 = 4014 → 9
- D = A + B + C = 40 → 4
- E = A + B + C + D = 44 → 8 — **центр месяца, 8 · Справедливость**
- F = A + B = 4, G = B + C = 3, H = C + D = 13, I = D + A = 14

## 6. От чего зависит центр

A зависит от дня рождения и выбранного месяца, B — от месяца рождения и выбранного месяца, C — от года
рождения и выбранного года и весь год одна и та же. У родившихся в один день и месяц разных лет
различается только C.

- родившиеся 19.01 любого года, январь 2026: 3 — 14, 4 — 4, 5 — 14, 6 — 14, 7 — 13, 8 — 14, 9 — 13, 10 — 14, 11 — 4, 16 — 1, 18 — 1, 20 — 10, 22 — 10 (центр — число лет)
