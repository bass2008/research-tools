# Лисовская — «Матрица Судьбы: Прогноз. Прогностика по Матрице Судьбы»

[Оглавление библиотеки](../README.md) · [Оригинал и доступ к разделам](sources/README.md)

Книга Юлианы Лисовской о **прогнозах по матрице** (2024): периоды жизни, кризисы, прогноз на год,
месяц и день, на место и документы — та же школа, что
[«Для начинающих»](../lisovskaya-beginners/README.md).

## Что есть в книге

| Ключ `read_section.py` | О чём |
|---|---|
| `periods` | периодность: десятилетия, годовой период, как читать матрицу после 80 лет |
| `purposes` | блок предназначений: расчёт и кризисы |
| `forecast` | прогноз на день, месяц и год целиком |
| `year` | прогноз на год: расчёт, как читать, общий прогноз на год |
| `place` | прогноз на страну, город, дом, документы, личную жизнь и финансы |
| `energies` | глава 3 целиком: 22 энергии в значении прогноза |
| `01` … `22` | одна энергия в значении прогноза |
| `pick` | как подбирать значения энергий |

**К продукту:** глава 3 и «Прогноз на год» — опора для страниц «N на год» (`/year/N`). Свой
персональный год калькулятор не считает (`decisions.md`, Decision 7): категория информационная,
расчёт по книге сверять с движком, прежде чем что-то обещать читателю.

## Что из книги в текст продукта не переносится

- Предсказания событий как неизбежных, сроки бед и болезней, медицина.
- Прогноз «на страну», «на документы» и подобное как факт — это практика автора.
- Текст не копировать: пересказывать своими словами, для цитаты — открыть оригинал.
