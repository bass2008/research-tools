`Лисовская Юлиана. Матрица судьбы Прогноз. Прогностика по Матрице судьбы 2024.fb2`.
Юлиана Лисовская, 06.05.2024, русский язык.

[source-map.json](source-map.json) содержит размер, SHA-256, полное оглавление (пути разделов
внутри FB2) и ключи разделов. Скрипт проверяет контрольную сумму и ничего не записывает:

```bash
python3 /home/sergey/Personal/research-tools/library/lisovskaya-prognosis/sources/read_section.py --list
python3 /home/sergey/Personal/research-tools/library/lisovskaya-prognosis/sources/read_section.py year
python3 /home/sergey/Personal/research-tools/library/lisovskaya-prognosis/sources/read_section.py 09
```

Иллюстрации в тексте отмечены маркером `[Иллюстрация]`; сами картинки — внутри FB2 (`binary`).
Оригинал не исправлялся.
