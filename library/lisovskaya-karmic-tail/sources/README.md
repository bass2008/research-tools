# Оригинал «Кармический хвост в Матрице Судьбы» и доступ к разделам

[Оглавление библиотеки](../../README.md) · [Книга](../README.md)

[FB2](karmicheskiy-hvost-v-matritse-sudby-2024.fb2) скопирован без изменений из файла пользователя
`Лисовская Ю. Кармический хвост в матрице судьбы.fb2`. Юлиана Лисовская, 15.05.2024, русский язык.

[source-map.json](source-map.json) содержит размер, SHA-256, полное оглавление (пути разделов
внутри FB2) и ключи разделов. Скрипт проверяет контрольную сумму и ничего не записывает:

```bash
python3 /home/sergey/Personal/research-tools/library/lisovskaya-karmic-tail/sources/read_section.py --list
python3 /home/sergey/Personal/research-tools/library/lisovskaya-karmic-tail/sources/read_section.py 15-20-5
python3 /home/sergey/Personal/research-tools/library/lisovskaya-karmic-tail/sources/read_section.py program
```

Иллюстрации в тексте отмечены маркером `[Иллюстрация]`; сами картинки — внутри FB2 (`binary`).
Оригинал не исправлялся.
