# Оригинал Holistic Tarot и доступ к разделам

[Оглавление библиотеки](../README.md)

Полный [EPUB](holistic-tarot-2015.epub) скопирован без изменений из файла пользователя `Benebell Wen. Holistic Tarot. 2015.epub`. Язык — английский, издатель — North Atlantic Books, 2015. Копия предназначена для сверки первоисточника; рабочие конспекты находятся в соседних папках `arcana/` и `general/`.

[source-map.json](source-map.json) содержит метаданные EPUB, размер, SHA-256, исходное оглавление и адреса выбранных разделов внутри архива. Номера страниц ридера меняются с настройками; для проверки пользоваться главой, названием и HTML-путём. Для карточек старших арканов прямое и перевёрнутое положения находятся в одном HTML-файле.

## Быстро открыть текст

Вспомогательный скрипт использует только стандартную библиотеку Python, проверяет контрольную сумму оригинала и ничего не записывает:

```bash
python /home/sergey/Personal/research-tools/library/benebell-wen/sources/read_section.py --list
python /home/sergey/Personal/research-tools/library/benebell-wen/sources/read_section.py 12-hanged-man
python /home/sergey/Personal/research-tools/library/benebell-wen/sources/read_section.py chakras
python /home/sergey/Personal/research-tools/library/benebell-wen/sources/read_section.py method
```

Ключи `00-fool` … `21-world` соответствуют именам рабочих карточек; остальные ключи перечисляет `--list`. `design` и `landscape` открывают соответствующие главы, `reversals` — краткую схему WIND и пример. Для других глав использовать полное оглавление из `source-map.json` и читать указанные HTML-файлы непосредственно из EPUB или открыть книгу в ридере.

Извлечение выдаёт текст, включая доступный текст таблиц. Изображения обозначаются маркерами с путём: если таблица или схема является картинкой, её нужно смотреть в оригинале. Текстовый вывод не заменяет визуальную проверку таких материалов. Разбивка слова внутри декоративных заголовков может сохраняться из EPUB.

## Поправки и происхождение конспекта

Оригинал не исправлялся: опубликованные автором поправки и редакционные ограничения вынесены в [отдельный документ](../general/05-known-issues.md). Не называть наши ограничения исправлениями, которые признала сама Вэнь.

Карточки и общие материалы — новый выборочный русский пересказ Codex, а не полный перевод или сокращённая авторская редакция книги. Для цитаты необходимо открыть оригинал; для спорного смыслового утверждения — прочитать абзац вместе с контекстом и соответствующее примечание.
