# Расхождения, ограничения и исправления

[Оглавление](../README.md)

Проверено по предоставленному EPUB 2015 года. «Не переносим» ниже означает редакционное решение для текстов проекта, а не утверждение, что в книге нет такого места. При запросе точного пересказа позиции Вэнь эти места следует честно описывать с атрибуцией.

## Содержательные ограничения

|---|---|---|

Не делать из карты доказательство правоты, преследования или обязанности простить обидчика. У Уэйта часть II отдельно ограничивает объяснение через мученичество; часть III всё же содержит жертву. |

| Успех, брак, богатство, беременность в значениях карт | Предсказательные утверждения и частные сценарии | В персональный отчёт по дате не переносить как установленные факты или гарантии. |

Разные толкования сами по себе не являются дефектом. Проблемы для нашей задачи — скрытое смешение авторов, необоснованная категоричность и переход от символа к факту без данных.

Печатные страницы приведены по странице исправлений; в EPUB надёжнее использовать название раздела и внутренний путь HTML. Оригинал сохраняется без исправлений для проверяемости. Наши содержательные ограничения выше — не авторские errata и не должны так называться.

## Покрытие проверки

Для этой рабочей выжимки изучены описания всех 22 старших арканов, расклад семи чакр, аналитическая последовательность главы 17 и нужные положения глав 15–16. Не заявляется полная проверка всех исторических гипотез, библиографических ссылок, младших арканов, астрологических таблиц и остальных глав книги.

Новый вопрос за пределами этого покрытия требует чтения соответствующего первоисточника, а не распространения статуса проверки на весь EPUB.
