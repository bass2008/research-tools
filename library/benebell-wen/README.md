Оригинал: **Holistic Tarot: An Integrative Approach to Using Tarot for Personal Growth**, North Atlantic Books, 2015, английский язык. Рабочие материалы подготовлены Codex 27.09.2026 по предоставленному пользователем EPUB.

Здесь сохранена полная книга и составлен выборочный конспект для нашей задачи: старшие арканы, контекст позиции, соединение карт и семь чакр. Цель не состояла в сокращении книги ровно наполовину. Младшие арканы и остальные методы доступны в оригинале, но не получили отдельных рабочих карточек.

## Статус и границы

Это рабочая редакционная библиотека. Она не устанавливает единственный истинный смысл карт и не гарантирует точность персонального разбора. Уэйт выбран основой символики проекта, Вэнь — источником контекстного объяснения и методики. Наши применения к матрице, её колонкам и комбинациям обозначены отдельно.

Ни одна из этих книг не даёт формулу нашей Матрицы, готовую систему кармических хвостов или толкование всех троек по дате рождения. Расклад семи чакр у Вэнь содержит по одной вытянутой карте на позицию. Подробное описание проверенного покрытия — в разделе ограничений.
