психология покупателя, цена, поисковая оптимизация. В список вошли только книги, которые можно
скачать. Это перечень: название, выходные данные и ссылка на страницу файла. Сами файлы не
скачивались. Собран 12.10.2026, 13:16–13:20 МСК.

Первый список, эзотерика, описан в [README.md](README.md). Этот собран другими скриптами, они
общие для любого набора разделов.

## Какие разделы и почему

Задача — поднять конверсию в покупку на нашем сайте и SEO. Поэтому взяты маркетинг, реклама,
продажи, интерфейсы, психология покупателя и цена. Список и исключения — в
`scripts/marketing-sections.txt`. Строка с `-` исключает подраздел. Периодика (`/periodic/`)
исключена везде.

Не взяты:
- сетевой маркетинг;
- подразделы «Поисковых движков» про Elasticsearch, Lucene/Solr, Sphinx, Shodan: это поиск для
  разработчиков, а не SEO;
- «Работа и бизнес» целиком (стартапы, карьера, трейдинг, недвижимость);
- Менеджмент;
- Финансово-экономические дисциплины, кроме ценообразования и поведенческой экономики;
- PR;
- Деловая коммуникация.

Чтобы добавить раздел, впишите его адрес в файл. Затем дообойдите его и пересоберите список
(команды ниже).

## Как собирали

Страница раздела twirpx отдаёт все свои файлы одним HTML, без пагинации. Скрипты запускаются
из `data/marketing/raw/`, между запросами пауза 1,5 с.

1. `crawl_sections.py <файл разделов>` проходит разделы и все вложенные подразделы. С каждой
   страницы за один проход берёт файлы со статусом (`data-status`), пометкой `limited` и типом
   (`data-file-type`). Файлы пишет в `items.jsonl`, страницы и счётчики вкладок — в
   `pages.jsonl`. Уже пройденные страницы пропускает, поэтому обход можно продолжить.
2. `build_sections.py <raw> <выход> <файл разделов>` собирает список и листы:
   - убирает журналы;
   - оставляет `approved`;
   - отсеивает не книги;
   - вытаскивает год и страницы из описания;
   - ставит отметки «про конверсию» и «SEO».

Пересобрать из сырых данных, без обращения к сайту:

```bash
conda activate research3.12
cd library/twirpx
python scripts/build_sections.py data/marketing/raw data/twirpx-marketing-spisok scripts/marketing-sections.txt
```

Обойти заново или дообойти новый раздел:

```bash
cd library/twirpx/data/marketing/raw
python -I ../../../scripts/crawl_sections.py ../../../scripts/marketing-sections.txt > crawl.log 2>&1
```

Полнота проверена по счётчикам сайта: в каждом из 11 корневых разделов собранные файлы плюс
файлы на вкладках учебных материалов дают ровно число раздела на сайте. Расхождение одно, на
1 файл, в «Поведенческой экономике».

### Как отсеяны не книги

В академических разделах («Академическая и специальная литература») twirpx показывает в списке
по умолчанию книги. Учебные материалы лежат на отдельных вкладках `?ft=`:
- курсовые, дипломные;
- контрольные, лабораторные;
- лекции, шпаргалки, рефераты;
- презентации, методички;
- статьи, диссертации и т. п.

Обход их не берёт, только считает. Книжные вкладки берёт: словари, энциклопедии, справочники.

В список по умолчанию всё равно просачиваются материалы без типа. Их сборка отсеивает:
- по типу файла;
- по названию: «Лекции по…», «Шпаргалка», «Шаблон -», «Кейс», «Аналитический отчёт»,
  «Сборник курсовых работ», брендбуки и т. п.;
- по началу описания: «Конспект лекций», «Курс лекций», «Методические указания».

Изданные практикумы и учебные пособия с выходными данными остаются: это книги. Они помечены в
колонке «Учебник».

### Капча и серый список

12.10 twirpx отвечал 403 с капчей: адрес 40.69.0.186, наш выход через exit node Tailscale,
попал в «серый список». 10.10 тот же скрипт ходил без капчи. Капча пройдена один раз через
форму `POST /ipsm/graylist-bypass/`, сайт выдал куку `SACT`. Кука лежит в
`data/marketing/raw/jar.txt`, и обход ходит с ней.

Если адрес снова попадёт в список, `crawl_sections.py` остановится со строкой `КАПЧА` в логе.
Чтобы продолжить:
1. Пройти капчу заново и сохранить куку в `jar.txt`.
2. Запустить обход ещё раз: пройденные страницы он пропустит.

Tailscale не трогать: без exit node пропадает выход в интернет. С сервера Arcana (45.80.130.166)
twirpx недоступен: соединение рвётся на TLS, похоже на блокировку по имени сайта.

## Ограничения

- **`limited` не расшифрован.** Пометка `data-limited="True"` стоит почти только у книг
  Springer, Apress и Palgrave. Анонимно страница такой книги выглядит так же, как у обычной.
  Что именно ограничено, видно только из аккаунта. Статус у них `approved`, поэтому они в
  списке, но с отметкой в колонке.
- **«Можно скачать» значит одно:** статус `approved`, файл не удалён по требованию
  правообладателя. Для скачивания сайт требует входа.
- **«Про конверсию», «SEO», «Учебник» и «Язык» — эвристики** по словам. Пустая ячейка не
  значит, что книга не про это.
- **Отсев не книг эвристический**: лист «Отсеяно — не книги» показывает, что ушло.
- **Снимок на 12.10.2026.** Обход занимает около 4 минут.
