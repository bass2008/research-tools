Список всех книг раздела «Эзотерика, мистицизм, оккультизм» сайта twirpx.com, которые можно
скачать. Это перечень, а не сами книги: название, выходные данные и ссылка на страницу файла.
Собран 10.10.2026, 22:00–23:02 МСК.

## Как собирали

Источник — https://www.twirpx.com/files/nonscience/isoteric/. Страница раздела отдаёт все файлы
раздела одним HTML, без пагинации. У каждого файла блок `div[data-object-type="file"]` с ID,
названием, форматами, размером, датой и описанием.

Скрипты запускаются по очереди из `data/raw/`: они читают и пишут файлы в текущем каталоге. Между
запросами пауза 1,5 с, User-Agent `Mozilla/5.0`, три попытки на страницу.

1. `crawl.py` берёт корень раздела (`isoteric-root.html`) и список подразделов из него — 254
   страницы. С каждой собирает файлы в `items.jsonl`, учёт страниц ведёт в `pages.jsonl`.
2. `crawl2.py` проходит рекурсивно. На страницах подразделов нашлись ещё 121 вложенный раздел,
   которых нет в корне: таро по колодам, практики и т. п. Всего страниц стало 375.
3. `crawl3.py` открывает три раздела, закрытые подтверждением «18+». Для этого он отправляет
   форму `POST /adult/confirm/` с `IsConfirmed=true` и дальше ходит с полученной кукой.
   Разделы: «Магические и сакральные сексуальные практики», «Крийя йога», «Тантрические
   сексуальные практики».
4. `status_crawl.py` заново проходит все 375 страниц с кукой «18+» и забирает статус каждого
   файла из атрибутов блока: `data-status` (`approved` — можно скачать, `copyright` — удалён по
   требованию правообладателя), `data-limited`, `data-file-type`. Результат — `status.jsonl`.
5. `build.py` склеивает всё и выкладывает список в `data/`:
   - убирает журналы;
   - оставляет только файлы со статусом `approved`;
   - вытаскивает год, страницы и выходные данные из описания.

Пересобрать список из сырых данных, без обращения к сайту:

```bash
conda activate research3.12
python library/twirpx/scripts/build.py
```

Проверено 12.10.2026: пересборка из `data/raw/` даёт тот же CSV, что и у владельца в
`~/Downloads`, все 23 104 строки совпадают.

## Ограничения

- **«Можно скачать» здесь значит одно:** у файла статус `approved`, то есть он не удалён по
  требованию правообладателя. Нужна ли для скачивания регистрация или другие условия сайта, не
  проверялось.
- **Журналы отсеяны по разделу и по виду названия.** Выпуски с необычным названием могли
  остаться.
- **Год и страницы взяты эвристикой** из начала описания. Пустая ячейка не значит, что данных нет
  на странице файла.
- **Снимок на 10.10.2026.** Новые файлы и удаления после этой даты в список не попали. Чтобы
  обновить, нужно заново пройти шаги 1–4: около часа запросов.
