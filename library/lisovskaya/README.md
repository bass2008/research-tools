# Юлиана Лисовская — «Матрица судьбы: совместимость»: рабочая библиотека

Оригинал: **Матрица судьбы: совместимость**, Юлиана Лисовская, Ridero, 2024, русский язык. Рабочие материалы подготовлены 05.10.2026 по PDF пользователя.

Единственный найденный письменный источник, где расчёт матрицы пары расписан по шагам и с примерами. Здесь сохранена полная книга и составлен выборочный конспект: расчёт с привязкой к движку продукта, смысл точек пары, методика чтения, нетипичная совместимость и энергии 2–22 в контексте пары.

## Статус и границы

Это школа Лисовской, а не канон Ладини: формулу совместимости Ладини публично не описывает. Расчёт книги проверен на движке продукта и совпадает полностью; толкования — практика автора, и она сама так их называет.

Книга не даёт готовых текстов на 97 хвостов пары, отдельных значений по всем точкам линий, возрастной шкалы и чакр для пары. Карточки пересказывают и минусы энергий, включая измены, зависимости и насилие; в тексте продукта это не утверждается о людях: см. [ограничения](general/05-known-issues.md).
