# Ограничения, опечатки и границы применения

[Оглавление](../README.md)

Редакционные заметки, 05.10.2026. Не исправления, признанные автором.

## Статус источника

- Книга самиздатовская (Ridero, 2024), автор — практикующий консультант со своими курсами. Это **школа Лисовской, а не канон Ладини**: Ладини формулу совместимости публично не описывает, её тренинг «Матрица совместимости» платный и закрытый.
- Автор сама называет значения точек пары своей практикой («я не претендую на истину»). Сложение точек она называет «общепринятым и классическим» способом.
- Расчёт проверен: личные матрицы совпадают с движком продукта, все 79 чисел пар из книги совпадают с поточечной суммой ([расчёт](01-calculation.md)). Толкования не проверяемы и остаются мнением автора.

## Чего в книге нет

- Отдельных толкований 97 хвостов пары: есть смысл линии и два разобранных хвоста (5-11-6, 17-5-6), плюс сфера «задачи пары» в каждой карточке.
- Отдельных значений для большинства точек линий по энергиям: глава 4 расписана по сферам (как выглядит, атмосфера, наполняет, финансы, задачи, рекомендации).
- Раздела «для чего встретились» по энергиям — только у 2, 3 и 4. Для остальных его приходится выводить из плюса энергии и связки Б+В.
- Возрастной шкалы, чакр, родовых линий для пары: автор их сознательно не использует.
- Подробных значений 22 энергий: автор прямо пишет, что даёт только базу.

## Границы применения в продукте

Карточки пересказывают автора полностью, включая минус. В тексте для читателя действуют правила [ArcanaSkill](../../../.agents/skills/arcana-skill/SKILL.md):

- **Не утверждать факты о паре**: измены, любовники, абьюз, насилие, зависимости, криминал, мошенничество, бесплодие, беременность, болезни, смерть, стихийные бедствия. У автора это перечни возможных минусов энергии, а не выводы о конкретных людях.
- **Не превращать пол в обязанности.** Формулы вроде «мужчина решает, женщина уступает» — позиция автора; в продукте роли партнёров не распределяются по полу.
- **Не назначать виноватого.** Шаг консультации «кто из партнёров создаёт трудности» (см. [методику](03-reading-method.md)) в продукт не переносится.
- **Не выдавать убеждения за механизмы.** «Материализация мыслей», привороты, «души договорились до рождения» — взгляды автора.
- **Без процентов совместимости.** Метод их не даёт, и автор их не использует.
- **Не копировать текст книги.** Автор просит не заниматься плагиатом и ссылаться на неё. Карточки — пересказ для внутренней работы; тексты продукта пишутся заново, своими словами.

## Нумерация

Энергии у автора — числа матрицы: 8 — Справедливость, 11 — Сила, 22 — Шут, как в продукте. У Уэйта и Вэнь VIII — Сила, XI — Справедливость, 0 — Шут; карточки ссылаются на их файлы по названию карты, а не по номеру.
