# Нетипичная совместимость: место, коллектив, сделка

[Оглавление](../README.md) · [Второй способ расчёта](01-calculation.md#второй-способ-сложение-дат)

**Источник:** глава 5 «Нетипичная совместимость», стр. 104–114 PDF. Выборочный пересказ, 05.10.2026.

Нужна дата рождения, основания или заключения объекта. Считается **сложением дат, а не матриц**: день с днём, месяц с месяцем, год с годом; суммы свёртываются, месяц не ограничен 12; на полученную «дату» строится обычная матрица. Блок предназначений не считается.

## Страна, город, дом, местность

Дата основания — когда объект получил нынешнее название. Для поездки достаточно внешнего колеса и центра, для переезда — ещё линий финансов и отношений.

| Точка | Значение |
|---|---|
| А | общие впечатления и события, «красная нить» |
| Б | как воспримут местные и как с ними взаимодействовать |
| В | только плюс поездки или переезда |
| Д | только минус |
| Г | материальная сторона: траты, цены, как изменится положение, как отразится на теле |
| Е | что понравится больше всего |
| Ё | что не понравится категорически |
| Ж, З | к чему не были готовы, в плюсе и минусе |
| Линия финансов | заработок, работа и реализация на новом месте |
| Линия отношений | местные жители, соседи, работодатель, новые друзья |

Пример: Великобритания (01.05.1707) и человек 03.10.1997 → 04.15.0014.

## Коллектив, компания, друзья

Складываются даты всех участников. Пример на пятерых: дни 1+5+14+10+20 = 50 → 5, месяцы → 6, годы 9933 → 24 → 6; матрица на 05.06.0006.

| Точка | Значение |
|---|---|
| А | атмосфера между людьми, без учёта начальства |
| Б | как руководитель или обратившийся человек видит коллектив |
| В | что объединяет |
| Д | что разобщает |
| Г | готовность поддержать материально, физические отношения в группе |
| Е | что сплачивает и вдохновляет |
| Ё | трудности понимания, почва конфликтов |
| Ж, З | что скрыто от руководителя |
| Линия финансов | удовлетворённость деньгами; читается целиком |
| Линия отношений | понимание и уважение внутри; читается целиком |

## Сделка, бизнес-партнёр

Складывают с датой договора, датой рождения партнёра или датой основания места. Пример: 20.05.1987 + 29.12.1973 → 13.17.0018.

| Точка | Значение |
|---|---|
| А | на чём будет держаться партнёрство |
| Б | как партнёр видит нас, в чём наше преимущество |
| В | плюс сделки, чего достигнут |
| Д | минусы, с которыми придётся смириться |
| Г | материальная выгода обоих |
| Е | результаты и выгода |
| Ё | трудности сотрудничества |
| Ж, З | что другая сторона может скрыть |
| Линия финансов | финансовый итог сделки |
| Линия отношений | как договариваться и держать уважение |

## Замечание о буквах

В главе 5 линия финансов обозначена буквами Н, М, Л, а линия отношений — И, К, Л; в главе 3 это Г1–Л–К и К–И–Д1. Это та же схема с другой разметкой рисунка: см. [ограничения](05-known-issues.md).
