# Артур Эдвард Уэйт: библиотека значений арканов

Основа — **The Pictorial Key to the Tarot** Артура Эдварда Уэйта с иллюстрациями Памелы Колман Смит. Первое издание — 1910 год; здесь сохранены транскрипция и скан переиздания **1922 года**. Библиотека подготовлена 27.09.2026.

Задача библиотеки — дать проверяемый источник для значений карт. В ней **22 отдельных файла старших арканов**, общие материалы и полный оригинал книги. Все 56 младших арканов присутствуют в оригинале; отдельные русские карточки для них здесь не составлялись.

## Статус русского материала

Русские тексты подготовлены **Codex** для этой библиотеки. Это рабочий конспект и перевод с английского, а не заимствованный современный русский перевод, не академическое издание и не утверждённый экспертом словарь. Авторские утверждения, перевод и редакционные ограничения разделены. Проверять спорную формулировку следует по приведённому оригиналу и скану.

Уэйт не описывает матрицу по дате рождения, семь чакр и колонки «физика / энергия / эмоции». Библиотека задаёт основу значений **карт**; связь с позициями матрицы требует отдельного обоснования. Перевёрнутые значения не превращены автоматически в «минусы» характера.
