# Термины и осторожные места перевода

[Оглавление библиотеки](../README.md)

Рабочие пояснения к языку именно этой книги. Это не универсальный словарь всех школ Таро, христианства или каббалы. Для цитирования следует возвращаться к английскому контексту.

## Устройство Таро и расклада

| Термин | Как понимать здесь |
|---|---|
| Trumps Major / Greater Arcana | Старшие арканы, 22 символические карты |
| Lesser / Minor Arcana | Младшие арканы, четыре масти |
| Divinatory meanings | Гадательные значения; отдельный слой книги, а не вся символика карты |
| Reversed | Перевёрнутая карта в процедуре гадания; не автоматически «плохой характер» |
| Querent | Вопрошающий — человек, для которого проводится гадание |
| Diviner | Человек, проводящий гадание |
| Significator | Карта, выбранная представлять человека или предмет вопроса в данном раскладе |
| Secret Tradition | «Тайная традиция» в авторской концепции; существование и происхождение этой традиции не проверяются данным справочником |

См. [классификацию в части I](https://en.wikisource.org/w/index.php?title=The_Pictorial_Key_to_the_Tarot/Part_1&oldid=15274505#12), [часть II, § 1](https://en.wikisource.org/w/index.php?title=The_Pictorial_Key_to_the_Tarot/Part_2&oldid=15274517#59), [описание расклада в части III](https://en.wikisource.org/w/index.php?title=The_Pictorial_Key_to_the_Tarot/Part_3&oldid=15274510#299).

## Духовный язык автора

| Термин / образ | Контекст у Уэйта |
|---|---|
| Divine / Spirit / Grace | Божественное, дух, благодать. Это религиозные понятия автора, а не просто синонимы мотивации, эмоций или физической энергии |
| Higher nature | Высшая природа человека в духовном объяснении; не равна любой социально одобряемой черте |
| Animal nature / passions | Животная природа и страсти; особенно существенны в Силе, Дьяволе, Луне и Солнце |
| Direct / reflected light | Непосредственный / отражённый свет. Солнце и Луна используют различие для объяснения сознания и границ рассудочного света |
| Tora | Свиток Жрицы: высший и тайный закон, второй смысл Слова в объяснении автора |
| Shekinah / Шехина | В объяснении Жрицы — сопребывающая, обитающая слава; автор связывает её с духовной Невестой и отражением высшего |
| Binah / Бина | Высшее Понимание в каббалистическом языке автора; появляется у Жрицы и Звезды |
| Malkuth / Малкут | Нижний мир / царство в том же объяснении Жрицы |
| Mystical death | Мистическая смерть: изменение формы сознания ещё при жизни; Уэйт отличает её от обычной смерти |
| Great Work | Великое Делание в мистико-алхимическом языке. Значение зависит от отрывка; термин нельзя везде заменять словом «проект» |
| Crux ansata | Крест с петлёй; так назван вид скипетра Императора |
| Fylfot | Историческое название крюкообразного креста; Уэйт употребляет его для положения ног Повешенного |

Контексты доступны в карточках [Мага](../arcana/01-magician.md), [Жрицы](../arcana/02-high-priestess.md), [Силы](../arcana/08-strength.md), [Повешенного](../arcana/12-hanged-man.md), [Смерти](../arcana/13-death.md), [Звезды](../arcana/17-star.md), [Луны](../arcana/18-moon.md) и [Солнца](../arcana/19-sun.md).

## Неоднозначные слова гадательного перечня

| Слово | Рабочее решение в библиотеке |
|---|---|
| Address | У Мага: обходительность / ловкость в обращении, не почтовый адрес |
| Science | У Жрицы: знание / наука в историческом языке, не доказанная научность метода |
| Credit | У Императора: доверие / кредит; контекст не фиксирует единственный современный финансовый смысл |
| Policy | У Отшельника: расчётливая тактика, не обязательно партийная политика |
| Executive | У Справедливости: исполнение / исполнительная власть; термин краткий и без авторского развёрнутого пояснения |
| Discernment | У Повешенного: проницательность, различение; не автоматически эмпатия или умение слушать |
| Body politic | У Повешенного: политическое сообщество, государственное целое; не физическое тело человека |
| Accommodation | У Умеренности: приспособление / согласование; не «жильё» без контекста |
| Impotence | У Звезды: бессилие; узкое медицинское значение не установлено |
| Bewrayment | У Шута: рабочее чтение как выдача тайны / разоблачение; архаическое слово требует осторожности |
| Distribution | У Шута сохранено буквально как «распределение»; в списке нет пояснения, позволяющего уверенно заменить его психологическим качеством |
| Flight | У Мира: бегство / перемещение; нельзя автоматически читать как современный авиаперелёт |

Источник этих слов: [часть III, § 3](https://en.wikisource.org/w/index.php?title=The_Pictorial_Key_to_the_Tarot/Part_3&oldid=15274510#283). Таблица объясняет переводческие решения; она не утверждает, что Уэйт сам дал такие словарные определения.
