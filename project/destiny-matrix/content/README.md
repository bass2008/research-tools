# Энциклопедия: источник контента

Текст живёт здесь, в `data/`. Фронт читает не эти модули, а собранный JSON в
`apps/web/content/` — он и есть артефакт сборки.

```bash
conda run -n research3.12 python -m content.encyclopedia.build      # собрать JSON
conda run -n research3.12 python -m content.encyclopedia.validate   # проверить целостность
conda run -n research3.12 python -m content.encyclopedia.selftest    # проверить сам валидатор
```

`build` перезаписывает четыре файла: `arcana.json`, `combinations.json`, `positions.json`,
`chakras.json`. Сборка детерминированная — без дат и случайностей, поэтому повторный прогон
даёт побайтово тот же результат, а diff показывает только правки текста.

## Что где лежит

| файл | что внутри |
|---|---|
| `data/arcana_a.py`, `data/arcana_b.py` | 22 аркана: название, слаг, короткая фраза, значение, плюсы и минусы, ключи |
| `data/in_positions/a*.py` | 440 толкований: каждый аркан в каждом из 20 разделов отчёта |
| `data/pairs/p*.py` | 231 сочетание пар `a < b`: короткая фраза и два абзаца |
| `data/sections_meta.py` | 20 разделов: о чём раздел, как читать, SEO |
| `data/points.py` | 17 точек карты: формула словами, значение, привязка к разделам |
| `data/chakras.py` | 7 чакр: значение уровня и смысл трёх колонок |
| `seo.py` | заголовки, описания и запросы; описание сочетания берётся из его же текста |

Модули в `in_positions/` и `pairs/` подхватываются автоматически: чтобы добавить порцию
текста, достаточно положить новый файл рядом.

## Правила, которые держит валидатор

- заголовки, вводки и доступ разделов не дублируются в контенте, а берутся из
  `engine.sections.SPEC`; ключи и порядок чакр — из `engine.matrix.CHAKRAS`;
- 22 аркана × 20 позиций — без пропусков; 231 пара — вся сетка, без дублей и без
  перевёрнутых пар;
- страниц ровно 298 (22 + 37 + 231 + 7 + корень), у каждой есть входящая ссылка и хотя бы
  одна исходящая, все `href` ведут на существующие страницы;
- ни одного повторяющегося текста, ни одного одинакового начала, ни одного канцелярского
  оборота из списка `BANNED`;
- один поисковый запрос закреплён за одной страницей.

Нижние планки по длине (`MIN_*` в `validate.py`) — защита от заглушек, а не мера качества:
средняя длина сочетания сейчас 403 знака при пороге 350.
