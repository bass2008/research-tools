# Переезд: Yandex Cloud против Selectel

Замеры в ночь на 19.09.2026. Три площадки, одинаковый образ `b3112b6`, одинаковая база —
копия боевой, восстановленная из бэкапа. Прод при этом работал как обычно и данных не потерял.

## Коротко

**Переезжать стоит, и брать надо две ядра, а не одно.**

| | Yandex Cloud | Selectel 1 ядро | Selectel 2 ядра |
|---|---:|---:|---:|
| цена в месяц | **1441 ₽** | **632 ₽** | **778 ₽** |
| статья, ответ сервера | 273 мс | 137 мс | 139 мс |
| печать PDF (устоявшаяся) | 7,1 с | 9,2–10,5 с | **7,1–7,7 с** |
| синхронная запись на диск | 249 IOPS | 1777 | **2384** |
| последовательная запись | 16 МБ/с | 318 | 316 |
| робот обошёл за 45 секунд | 127 страниц | 261 | **266** |

Три вывода, каждый подтверждён числами ниже:

1. **Диск быстрее в разы, а не в процентах.** Синхронная запись, от которой зависит отклик
   SQLite, — в 7–10 раз. Поток — в 20 раз. Это то, ради чего всё затевалось.
2. **Второе ядро окупается именно печатью.** На одном ядре PDF печатается 9–10 секунд, на двух
   — 7. Разница 150 ₽ в месяц за треть времени печати: человек, который заплатил 250 ₽, ждёт
   свой файл на три секунды меньше.
3. **Отдача страниц вдвое быстрее**, но здесь надо быть осторожным: часть разницы — сеть и TLS,
   а не сервер. Чистая работа сервера (замер изнутри машины) почти одинаковая: 7–8 мс.

## Чего эти замеры не показывают

- **Прод меряется по HTTPS, копии по HTTP.** Рукопожатие TLS добавляет проду 100–200 мс. Раздел
  «из чего складывается время» это разделяет, но полностью честным сравнение станет только
  после выпуска сертификата на новой машине.
- **Копии стоят в ru-7 (Москва), прод — в ru-central1-a.** Пинг с моей машины: 12–17 мс против
  0,4 мс у прода до Москвы. География разная, и на числа снаружи это влияет.
- **Одно ядро против двух проверялось на пустой машине.** При живом трафике разница может
  оказаться больше: сейчас печать конкурирует только сама с собой.
- **Одна ночь.** Соседи по хосту у дешёвого VDS меняются, и повторить замер днём стоит.

## Что делать

**Брать `VDS 2-2-40` за 396 ₽, а не `1-2-25` за 250 ₽.** Разница 150 ₽ покрывается тем, что
печать возвращается к нынешним семи секундам вместо десяти, и остаётся запас на вторую
одновременную. При этом общий счёт всё равно вдвое ниже нынешнего: 778 ₽ против 1441 ₽.

Экономия — **663 ₽ в месяц, около 8000 ₽ в год**. С учётом того, что сайт заработал 500 ₽ за
всё время, это половина разницы между «проект стоит как две чашки кофе» и «как подписка,
которой не пользуешься».

### Что мешает съехать прямо сейчас

| Препятствие | Что нужно |
|---|---|
| сертификаты | выписать Let's Encrypt после переключения DNS — до этого сайт по HTTP |
| DNS | перенести зону и сменить NS у регистратора: там MX, SPF, DKIM и DMARC `p=reject`, ошибка ломает чеки покупателям |
| лендинг `.com` | лежит в Object Storage Яндекса, переносится отдельно |
| роутер за 194 ₽ | убирается только публичной подсетью, а она аккаунту закрыта — нужен тикет в поддержку |

### Порядок, который предлагаю

1. Тикет в Selectel на публичные подсети — пока идёт переписка, всё остальное делается.
2. Пересоздать машину как `2-2-40`, развернуть на ней копию (скрипт `infra/deploy-selectel.sh` уже есть).
3. Перенести DNS в Cloudflare отдельным днём, дождаться распространения, проверить почту.
4. Переключить A-записи, выписать сертификаты, прогнать e2e против нового прода.
5. Держать старую машину неделю выключенной, но не удалённой — на случай отката.

## Как воспроизвести

Все скрипты и сырые данные — в рабочем каталоге замера:

| файл | что |
|---|---|
| `http_bench.py` | страницы, параллель, обход роботом, путь посетителя, длительная нагрузка |
| `phases.py` | раскладка времени: DNS, соединение, TLS, ожидание сервера, тело |
| `payload/page_bench.py` | те же страницы изнутри машины, без интернета |
| `payload/print_bench.py` | печать PDF: три подряд и две одновременно |
| `payload/cpu_disk.py` | процессор в один поток и на все ядра, диск в четырёх профилях |
| `mixed.py` | робот и читатель одновременно, печать под нагрузкой, холодный старт |
| `cost.py` | стоимость по позициям |
| `*-results.json` | сырые числа каждого набора |
