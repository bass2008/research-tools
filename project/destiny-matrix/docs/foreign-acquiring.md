# Зарубежный эквайринг

> Исследование будущего приёма денег вне России. Зарубежный провайдер не подключён;
> варианты и расчёты ниже — прежние рабочие предположения, а не текущая конфигурация.
> Перед реализацией нужно заново проверить условия провайдеров, цены и требования.

## Текущее состояние на 26.09.2026

Приложение уже объединено: один frontend, один API и одна БД на окружение.
Правила языков — в [runtime-localization.md](runtime-localization.md).
Доступ общий для RU/EN, `ALL_FREE_WITHOUT_PAYMENT=0`. Смена языка не выбирает продавца,
провайдера, валюту или бесплатность. Задача зарубежного эквайринга отложена отдельно.

Разделы ниже описывают проект возможного подключения; наличие в них «выбран» или схемы
запросов не означает, что это уже реализовано.

## 1. Зачем

Т-Банк — российский эквайринг, карты иностранных банков не принимает: cross-border отключён.
Покупатель вне России на `.ru` заплатить не может.

Сегмент: 27,5 % показов `.ru` вне России (GSC, 8 дней) — Украина, Казахстан, Беларусь, США,
Турция, Польша.

Язык не равно карта, а IP не различает четыре комбинации (россиянин с зарубежной картой,
эмигрант с российской, VPN в обе стороны). **Способ оплаты выбирает человек**, гео решает только
порядок кнопок.

## 2. Провайдер: Lemon Squeezy

| | почему не он |
|---|---|
| **Lemon Squeezy** | **выбран**: эзотерики нет ни в prohibited, ни в restricted; ОАЭ в списке стран продавца; работает у конкурента `destinymatrixchart.net` |
| Paddle | AUP запрещает «pseudo-science, including but not limited to clairvoyance, horoscopes, fortune-telling» |
| Stripe | требует UAE trade licence |
| PayPal | не MoR: НДС ЕС и sales tax США на нас, при тех же ~6,4 % |
| Creem | дешевле (3,9 % + $0,40), но 15 месяцев на рынке, категория не проверена, жалобы на изъятие средств |
| Gumroad | резерв: 10 % **без фикса** — выгоднее LS на чеке до $14; категория не проверена |

Paddle — под будущие не-эзотерические продукты. Аккаунты MoR не эксклюзивны: один товар — один
канал.

## 3. Условия LS

| | |
|---|---|
| комиссия | `$0,50 + 5 %` + 1,5 % международная + 0,5 % подписка |
| выплата | 1 % на счёт вне США (PayPal 3 % — дороже) |
| порог, график | $50; 1-го и 15-го, продажи держатся 13 дней |
| верификация | Emirates ID или паспорт, удалённо, бумажных писем нет |
| store URL | **`arcana-sense.com`** — LS проверяет магазин и его сайт, а на `.ru` другой продавец |
| покупатели | Россия и Беларусь отсечены: «Unsupported countries for purchases» |

## 4. Схема

Возможная схема в общем приложении: **продавец выбирается валютой тарифа**, а не языком.
Это предложение для будущего эквайринга; текущий код так провайдера не выбирает:

```
тариф RUB → PROVIDERS["tbank"]         продавец: ИП   домен: arcana-sense.ru
тариф USD → PROVIDERS["lemonsqueezy"]  продавец: LS   домен: arcana-sense.com
```

| | `.ru` | `.com` |
|---|---|---|
| контент, цена | русский, 250 ₽ | английский, $5 |
| продавец, оферта | ИП, Т-Банк | Lemon Squeezy |
| `/pay`, `/pay/done` | — | русская и английская, **`noindex`** |

Русская страница оплаты на `.com` дублей не создаёт — они считаются по индексируемым страницам.
Публичная индексируемая версия `.com` остаётся английской, но посетитель уже может
переключить интерфейс и материалы на русский в том же приложении.

## 5. Цены

Прайсы независимы, это не пересчёт по курсу. Паритет с 250 ₽ — **$3,72** (курс 86,19).
Ставим **$5**: у $4 не хватает курсового запаса.

| курс ₽/$ | $4 | $5 |
|---|---|---|
| 86 | 271 ₽ | 350 ₽ |
| 75 | **237 ₽ — ниже рублёвой** | 305 ₽ |
| порог окупаемости | 79 ₽/$ | 61 ₽/$ |

Ниже $4 нельзя: фиксированные 50 центов дают 25 % потерь на чеке $3. Дно англоязычного рынка —
$8 (`datemyst.com` от $7,97), типовая разовая цена $19; поднимать до рыночной имеет смысл на
`.com`, где рублёвого прайса рядом нет.

## 6. Поток оплаты

Предлагаемый сценарий для будущего провайдера. Сейчас аккаунты общие, cookie между
доменами не передаются, а текущий `/api/payments/sync` требует авторизацию покупателя.
Доступ к результату по одному `order_id` не реализован и не должен считаться безопасным
способом переноса сессии. До реализации нужно спроектировать проверку владельца и возврат
на исходный домен с сохранением языка.

1. Вход на `.ru` → есть `email`.
2. «Зарубежная карта» → api создаёт `Payment`, возвращает `order_id`.
3. `arcana-sense.com/pay?order=<id>` — условия LS, их чекаут. **Дата рождения не передаётся.**
4. Оплата.
5. Вебхук `order_created` → api → `Payment.paid_at` + `Entitlement` (как у Т-Банка).
6. Success URL → `arcana-sense.ru/pay/done?order=<id>`.

Кнопки называются по инструменту, а не по языку — «Российская карта — 250 ₽» и «Зарубежная
карта — $5», обе видны всегда. Рядом со второй — строка, что оплата пройдёт на `arcana-sense.com`
и чек придёт от Lemon Squeezy: иначе покупатель не узнаёт списание в выписке и оспорит его,
а чарджбэк стоит $30 и портит риск-профиль.

## 7. Что доделать в коде

| место | что |
|---|---|
| `api/app/tariffs.py` | колонка `currency`, запись тарифа в USD |
| `api/app/payments/lemonsqueezy.py` | провайдер по протоколу `Provider` (образец — `tbank.py`) |
| `api/app/payments/__init__.py` | регистрация в `PROVIDERS`, выбор по валюте |
| вебхук | `order_created` рядом с обработчиком Т-Банка |
| `web/lib/tariffs.ts` | убрать жёсткий `₽` и `toLocaleString` |
| документы и оплата | страницы `/pay` уже существуют; для LS нужны согласованные условия, возвраты и проверка владельца заказа |

## 8. Риски

**Заморозка.** Terms LS: «has the right to delay payouts for risk assessment, suspend accounts,
and refund payouts without warning». Список запрещённых продуктов меняется «without notice, all
changes take effect immediately». В транзите постоянно висит две-четыре недели выручки — это
размер возможной потери; публичные случаи есть ($2 000+ с отменой сотни заказов).
Отсюда: выплаты не копить, сторы держать живыми, payout invoices скачивать — они же нужны банку
как подтверждение источника средств.

**Чарджбэки.** Работает оферта («несогласие с содержанием не является недостатком работ») — её
надо перевести и показывать до оплаты.

**Потеря резидентства ОАЭ.** Счёт в Mashreq закроют вместе с визой. В списке LS есть Казахстан,
Узбекистан, Армения, Азербайджан; Таджикистана и Кыргызстана нет. Открыто: можно ли сменить
страну счёта без пересоздания аккаунта — у Stripe страна неизменна.

## 9. Чего не делать

- не создавать вторую индексируемую русскую копию корпуса на `.com`; переключение интерфейса уже поддерживается;
- не ставить LS-чекаут на страницу разбора `.ru` — два продавца в магазине, который проверяет LS;
- не выбирать провайдера по IP;
- не ставить цену ниже $4;
- не проводить матрицу через Paddle — запрет цитируемый.
