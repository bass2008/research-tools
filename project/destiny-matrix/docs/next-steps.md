## Что стоит между сегодняшним состоянием и первым рублём

Всё остальное в этом документе можно отложить, а эти четыре пункта — нет.

1. **Реальный приём платежей.** Сейчас `/api/payments/mock` всегда отвечает успехом. Нужен
   провайдер, чеки по 54-ФЗ и вебхук подтверждения. Первый шаг ничего не стоит: спросить
   провайдера, берёт ли он тематику — ОКВЭД 96.09 прямо включает деятельность астрологов,
   и отказ отменяет всю ветку с продажей.
2. **Реквизиты и юридические страницы.** Тексты оферты, политики и возврата написаны, но в них
   стоят заглушки `⟨ИП Фамилия И. О.⟩`, `⟨ИНН⟩`, `⟨ОГРНИП⟩`. Пока они там, модерация Директа
   страницу не пропустит.
3. **Уведомление РКН об обработке персональных данных** — до первого собранного письма,
   подаётся личной подписью через ЕСИА.
4. **Восстановление пароля.** Купивший получает пароль один раз на экране. Писем система не
   отправляет вовсе, поэтому потеря пароля означает потерю доступа. Нужна отправка почты
   (хотя бы через внешний SMTP) и сброс по ссылке.

## Тесты

- **Postgres ни разу не проверялся.** Всё гонялось на sqlite: docker выключен. Нужен прогон
  миграций и всех тестов API на настоящем Postgres, иначе первый деплой станет первым запуском.
- **Нет тестов на срок тарифа**: истёкший `year` должен закрывать платные разделы.
- **Нет проверки паритета движков на всём диапазоне.** TypeScript-порт сверен с Python на 400
  случайных датах; полный перебор — 5 544 матрицы — занимает секунды и закрывает вопрос
  навсегда.
- **Нет теста на гонку лимита.** Барьер сделан атомарным `UPDATE`, но одновременные запросы
  в тесте не бьются.
- **Нет нагрузочной проверки.** Неизвестно, сколько держит node на одной виртуалке: нужен
  простой прогон в 50 параллельных запросов по `/report` и `/encyclopedia`.

## Браузерные проверки

Selenium выпилен: набор проверял тарифы, которых больше нет, брал токен из тела ответа (он
живёт в httpOnly-куке) и оставлял в `/tmp` профили Chrome — 751 каталог на 5,2 ГБ за ночь.
Что осталось непокрытым без него и что нужно, если набор возвращать:

- подделка `localStorage` не открывает платное;
- показанный после оплаты пароль действительно работает;
- истёкшее право закрывает доступ, а матрицы в кабинете остаются;
- чужая матрица отдаёт 404, запрос без куки — 401;
- прогон в CI: сценарии запускались только руками.

## Инфраструктура

- **Проверка релиза после деплоя обязательна, и не по коду ответа.** Поймано на живом стенде:
  node отдавал HTML со ссылками на чанки прежней сборки, `curl /` возвращал 200, а в браузере
  приложение падало с «Application error». Одного кода ответа недостаточно — `check.sh` должен
  открывать страницу браузером и валиться на любой ошибке консоли и на любом запросе, не
  вернувшем 200.
- **Terraform ни разу не применялся.** Всё проверено только `validate`; первый `apply` покажет
  то, чего валидатор не видит.
- **Нет бэкапов Postgres.** Нужен `pg_dump` по расписанию в Object Storage с проверкой
  восстановления.
- **Нет мониторинга.** Ни аптайма, ни алертов: падение службы заметит посетитель, не мы.
- **Нет CI.** Тесты и сборка гоняются руками; нужен хотя бы прогон на push.
- **Логи никуда не собираются** — только `journalctl` на машине.
- **Один сервер без резерва.** Для проверки гипотезы нормально, но стоит знать цену: падение
  машины — простой сайта.

## SEO

- **Страницы матриц не заполнены смыслом.** 5 544 страницы собираются, но текст на них —
  общий разбор позиций. Поисковики такое склеивают как дубли: нужен уникальный вводный абзац
  на каждую матрицу.
- **Нет разметки Schema.org** для энциклопедии (`Article`, `BreadcrumbList`).
- **Нет перелинковки «похожие матрицы»** — соседние по одному изменённому числу.
- **Не собраны ключи под энциклопедию.** SEO-заголовки написаны по шаблону, частоты Вордстата
  для длинного хвоста вида «14 аркан в отношениях» не проверялись — а это ровно та ниша без
  конкуренции, ради которой энциклопедия и строилась.
- **Нет страниц под запросы «матрица судьбы рассчитать бесплатно»** и подобные — самые частотные
  в ветке.
- **Скорость не измерялась.** Ни Lighthouse, ни Core Web Vitals; при 5 544 страницах и картинках
  арканов это стоит проверить до закупки трафика.
