# Браузерные сценарии

Ходят по сайту так, как ходит человек: клики, ввод, переходы. Подмены состояния и прямых
запросов к api здесь нет — только то, что доступно из браузера.

```bash
cd compose && PAYMENT_PROVIDER=mock MAIL_TO_LOG=1 ./scripts/run.sh   # стенд на мок-оплате
cd ../e2e  && conda run -n research3.12 python -m pytest . -q        # ~65 c, 15 сценариев
```

`PAYMENT_PROVIDER=mock` обязателен: иначе покупка уйдёт на живую форму банка.
`MAIL_TO_LOG=1` держит письма в логе api — оттуда сценарий восстановления пароля берёт ссылку.

Прогон идёт на общей базе стенда и ничего не чистит: у каждого теста своя случайная почта, поэтому
повторные запуски не мешают друг другу.
