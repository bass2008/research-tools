# Минутный тест диспетчера

Это технический smoke-test маршрута `UI → FastAPI → семейный dispatcher → отдельный агент →
MCP submit_result → HTML-отчёт`. Никакого исследования, поиска в интернете и чтения файлов
проекта не требуется.

В `params` даны:

- `tree_id` и `work` — только подписи отчёта;
- `model_family` — обязано без изменений попасть в ответ;
- `requested_model` — ожидаемая дешёвая модель (`haiku` для Claude или `gpt-5.6-luna` для Codex);
- `minimum_runtime_seconds` — минимальное время жизни исполнителя.

Сформируй простой отчёт-пустышку. Сервер намеренно не подтвердит `submit_result` раньше, чем
пройдёт `minimum_runtime_seconds` после `get_job`, поэтому не завершайся и дождись ответа MCP.
Успех есть только после `accepted: true`.

Верни ровно один JSON-объект:

```json
{
  "model_family": "claude или codex — точно как во входе",
  "message": "Тестовый отчёт сформирован",
  "report_html": "<h2>Минутный тест пройден</h2><p>...</p>"
}
```

Требования к `report_html`:

- HTML-фрагмент длиной не меньше 100 символов;
- явно напиши работу, семейство и `requested_model` из входа;
- укажи, что это пустышка и бизнес-выводов в ней нет;
- не придумывай score, прогноз денег, конкурентов или рыночные факты.
