# stopwords — какие слова ветки не стоит покупать

Ветку дерева запросов краулят целиком, и каждый узел стоит денег. Твоя работа — просмотреть
слова, встречающиеся в ветке, и отметить те, что ведут в заведомо тупиковые запросы.

Твой ответ — **предложение**, а не фильтр: в список исключений попадёт только то, что человек
подтвердит руками. Поэтому лучше предложить лишнее с честным обоснованием, чем промолчать.

## Вход

```
{ "root": "телеграм",                       // корень ветки
  "root_freq": 5475727,
  "already_saved": ["проститутки", ...],    // уже в списке исключений — их не повторяй
  "words": [ { "word": "москва", "phrases": 214, "top_freq": 51000,
               "examples": ["телеграм москва", ...] } ] }
```

`phrases` — в скольких фразах ветки слово встречается, `top_freq` — частота самой частотной из
них. **Частоты не складывай**: у Вордстата широкое соответствие, число общей фразы уже включает
свои уточнения.

## Три категории

- **`stop`** — то, что мы не покупаем никогда: порнография, наркотики, оружие, взлом, слив
  персональных данных, обход блокировок, мошенничество. Ветка под таким словом целиком мусорная.
- **`brand`** — имя конкретного продукта, компании, канала или человека («подоляка», «дуров»,
  «premium»). Такой запрос — вход в чужой продукт, а не работа, которую можно сделать самому.
  Осторожно: слово может быть и брендом, и нарицательным («альфа», «звезда») — если сомневаешься,
  клади в `unwanted` и объясни.
- **`unwanted`** — не запрещённое и не бренд, но продуктовой работы там нет: новости и СМИ,
  «скачать бесплатно» в смысле пиратства, вакансии и заработок, гадания, знакомства, чужие
  географии. Сюда же — слова, которые уводят в соседнюю нишу, не связанную с корнем.

Слово оставляй **без категории (не возвращай вовсе)**, если под ним может быть настоящая работа:
инструменты, «как сделать», форматы, профессиональные контексты. Пропустить полезное слово дороже,
чем не отфильтровать мусорное: недобранный запрос стоит денег один раз, а потерянная ниша — совсем.

## Правила

1. **Возвращай только слова из `words`.** Выдуманное слово будет отброшено на приёме.
2. Одно слово — одна категория, самая точная.
3. Смотри на `examples`: слово оценивается по фразам, в которых оно живёт, а не само по себе.
4. У каждого слова — короткое `why` (одна строка, по-русски): почему это тупик. Человек будет
   решать по нему, и «мусор» объяснением не считается.
5. Слово из `already_saved` не возвращай ни в какой категории.

## Выход (JSON)

```
{ "stop":     [ {"word": "...", "why": "..."} ],
  "brand":    [ {"word": "...", "why": "..."} ],
  "unwanted": [ {"word": "...", "why": "..."} ] }
```

Пустая категория — пустой список. Ничего, кроме этого объекта, возвращать не надо.
