# score — оценка ниши по выдаче (Haiku, батч)

По работе и её выдаче (Яндекс топ-10 + Google топ-10) поставь **score 0–100** =
«насколько это реальная работа, которую НИЧТО в выдаче адекватно не закрывает».
**100** — нет профильного инструмента под ЭТУ работу (строить первым). **0** — всё занято
(профильные инструменты + сильные бренды в топе). Score — это ОБРАТНАЯ конкуренция, не
«много трафика». `freq` — только контекст, НЕ входит в оценку.

## Вход (батч 8–15)
```
{ "items": [ { "phrase": "...", "freq": 1234,
    "yandex": [ {"rank":1,"url":"...","title":"...","snippet":"..."}, ... ],
    "google": [ ... ] }, ... ] }
```
Пустой движок → `[]` (это сильный сигнал «не обслужено», не выкидывай ключ). Рассуждай
только по данному, ничего не додумывай.

## Сигналы

**Возможность (score ↑):**
| код | вес | на RU-выдаче |
|---|---|---|
| `NO_DEDICATED_TOOL` | 40 (гейт) | нет результата-инструмента под ЭТУ работу |
| `UGC_FORUM_QA` | 20 | спрашивают, не обслуживают: Ответы mail.ru, Яндекс Кью, pikabu, 4pda, VK, woman.ru |
| `GENERIC_PARTIAL_MATCH` | 15 | отвечают на родительскую категорию/шире, не на конкретную работу |
| `THIN_OLD_CONTENT` | 12 | тонкие/устаревшие страницы (2–5+ лет), контент-фермы |
| `HOMEPAGE_NOT_DEEP` | 12 | ранжируются главной/разделом, не глубокой страницей под запрос |
| `LANG_REGION_MISMATCH` | 10 | иностранные инструменты из-за отсутствия RU-аналога |
| `LOW_ADS` | 5 | мало рекламы при реальном спросе |

**Насыщение (score ↓):**
| код | вес | на RU-выдаче |
|---|---|---|
| `DEDICATED_TOOL_TOP` | 40 (гейт) | профильный инструмент под ЭТУ работу в топ-3 |
| `BIGBRAND_AGGREGATOR` | 25 | Яндекс-сервисы, ozon/wb/avito/dns/госуслуги/банки… |
| `STRONG_DEEP_PAGES` | 20 | несколько глубоких качественных страниц по теме |
| `HIGH_ADS_RELEVANT` | 10 | плотная релевантная реклама (Директ/Ads) |
| `FRESH_ONTOPIC` | 10 | свежий, точный, под работу контент |

## Формула (Яндекс 0.6 / Google 0.4)
1. `competition_engine = clamp(0..100, 50 + Σ(насыщение) − Σ(возможность))` по топ-10 движка.
   Пустой движок → competition ≈ 15.
2. `base = 100 − (0.6·competition_yandex + 0.4·competition_google)`.
3. Гейт-кэпы: профильный инструмент в топ-3 ОБОИХ → `min(base, 15)`; иначе любой движок с
   `competition ≥ 80` → `min(base, 35)`.
4. Нюанс ±10: оба движка UGC без инструмента → +10; только иностранные инструменты → +5;
   сомнение, что partial-match закрывает работу → −10 (лучше консервативнее).
5. clamp 0–100, округлить до 5.

Правило: weak+weak → 80–100; weak+served → 20–50; served+served → 0–20.

## Выход
Массив той же длины/порядка, ключ выравнивания — `phrase`:
```
{ "results": [ {
  "phrase": "...",
  "score": 0-100,
  "weights": {"yandex": 0.6, "google": 0.4},
  "competition_yandex": 0-100,
  "competition_google": 0-100,
  "description": "1–3 предложения: что ищут / что в выдаче / чего не хватает",
  "signals": [ {"code":"NO_DEDICATED_TOOL","direction":"opportunity","weight":40,"evidence":"конкретный домен/тайтл/ранг"}, ... ]
} ] }
```
`score` — итог (после гейт-кэпов и ±10). **Верни и два сырых входа `competition_yandex/google`
(0–100 на движок) и `weights`** — не только `score`: из них база `100−(w_y·c_y+w_g·c_g)` и гейты
пересчитываются под любые веса **без повторного прогона LLM**. Один усреднённый «raw» НЕ храним —
он уже зашит весами и для перекалибровки бесполезен.

Неоцениваемый (обе выдачи пусты из-за ошибки) → `{ "phrase": "...", "score": null, ... }` —
не выкидывай. (Порог `score > 60` → SCORED, `≤ 60` → LOW_SCORED применяет оркестратор.)

## Примеры (для калибровки)
- `конвертировать pdf в word онлайн` → ~10 (обе выдачи — профильные конвертеры + реклама).
- `рассчитать декретные выплаты 2026 калькулятор` → ~50 (калькуляторы есть, но B2B/за
  триалом, не под конечного пользователя; гейт не бьёт).
- `составить меню на неделю из того что есть в холодильнике` → ~85 (только общие рецептовые
  агрегаторы + UGC, англ. supercook.com на Google, RU-инструмента нет).
