# season — есть ли у работы сезонность (короткий комментарий)

Тебе дан **помесячный ряд частоты** самой частотной фразы работы за два года и посчитанная по
нему сводка. График нарисует система — от тебя нужен **смысл**, а не пересказ чисел.

## Вход

```
{ "work": "подготовить материалы к уроку",
  "phrase": "нейросети для создания урока",
  "series": [ {"ym": "2024-04", "y": 294}, ... ],
  "stats": {"min":109,"max":1299,"amplitude":11.9,"peak_months":["11","09","10"],
            "trough_months":["08","06","07"],"last":443,"yoy":1.39,"points":24} }
```

Ряд снят по одной фразе намеренно: формулировки одной работы колеблются вместе, и платить за
двадцать копий одного профиля незачем.

## Что оценить

1. **Есть ли сезонность вообще.** Размах в 1.5 раза — это шум, в 5–10 раз — выраженный цикл.
   Скажи прямо: есть или нет.
2. **Чем она объясняется.** Учебный год, праздники, отпуска, налоговые сроки, погода. Если
   объяснения не видишь — так и скажи, не выдумывай.
3. **Где мы сейчас.** Последняя точка — это пик, дно или середина? Во сколько раз она отличается
   от пика? Это главное: по цифре из мёртвого сезона нишу легко похоронить зря.
4. **Тренд год к году.** `yoy` — отношение второго года к первому. Растёт, падает, стоит.
5. **Что это значит для решения.** Одна фраза: на какую цифру опираться при оценке ниши и когда
   имеет смысл выходить.

## Выход (JSON)

```
{
  "seasonal": true | false,
  "amplitude_x": 11.9,
  "phase": "дно" | "рост" | "пик" | "спад",
  "peak": "сентябрь-ноябрь",
  "trough": "июнь-август",
  "trend": "рост x1.4 год к году" | "стабильно" | "падение x0.8",
  "comment": "3-5 предложений: есть ли сезонность, чем объясняется, где мы сейчас и на какую цифру опираться"
}
```

Пиши по делу. `comment` — это то, что человек прочитает вместо графика, если смотреть некогда.
