# adjacent — смежные ключи работы (без слова-технологии)

Дерево запросов выросло из одной ветки (например «нейросеть …»), поэтому мы видим спрос
**только среди тех, кто уже думает про технологию**. Учитель, который ищет «генератор рабочих
листов», в нашу статистику не попал вообще. Твоя задача — назвать фразы, которыми ту же работу
ищут **обычными словами**, чтобы измерить настоящий размер ниши.

## Что от тебя нужно

**Разные КОРНИ, а не варианты одной фразы.** «рабочие листы онлайн» и «рабочие листы бесплатно» —
это одно и то же, толку от них нет. Нужны разные способы назвать тот же результат:
«рабочие листы» / «конструктор заданий» / «карточки для урока» / «раздаточный материал».

Правила:

- **6–8 фраз** в первом заходе. Каждая — самостоятельный корень.
- **Без слова-технологии** («нейросеть», «ии», «gpt») — оно и есть наш перекос.
- **Коротко**: 2–4 слова. Уточнения («бесплатно», «онлайн») не нужны — система сама получит их
  из пула каждой фразы.
- Только то, чем **реально ищут** эту работу. Не выдумывай терминов, которых люди не пишут.

Полное семантическое ядро не собираем. Цель — покрыть основные способы назвать работу, чтобы не
потерять нишу из-за пропущенного корня.

## Вход

```
{ "work": "подготовить материалы к уроку",
  "why": "почему сборка считает это одной работой",
  "phrases": [ {"phrase": "нейросети для создания урока", "freq": 350}, ... ],
  "measured": { "рабочие листы": {"freq": 5400, "top": ["...", "..."]} }   // на втором заходе
}
```

## Выход (JSON)

**Первый заход** (`measured` пуст) — только список:

```
{ "keys": ["рабочие листы", "конструктор заданий", ...] }
```

**Второй заход** (`measured` заполнен) — вывод и, если нужно, добор:

```
{
  "more_keys": ["ещё корень, если он всплыл в пулах и мы его пропустили"],
  "covered": 0-100,
  "total_freq": 12800,
  "comment": "3-6 предложений: во сколько раз ниша больше нашей ветки, какие корни оказались
              главными, что осталось непокрытым и почему"
}
```

`more_keys` — **до 4 фраз** и только если в пулах видно корень, которого нет в измеренных.
Нечего добавить — пустой список. `covered` — твоя честная оценка, какую долю ниши покрыли; если
чувствуешь, что осталось много, так и напиши в `comment`, не завышай.
