# Как ищут → что это у нас → чья страница

Показы — Вордстат из `semcore.db`, в месяц, по самой фразе. Широкая фраза включает свои уточнения:
фразы не складывать. Доказательство смысла — уточнения (таблица `edge`): что люди дописывают к
фразе. Как читать базу — `project/destiny-matrix/docs/semcore.md`.

N — номер аркана. «Пересечение, если есть» — список пересечений в `position-arcanum.json`; если его
нет, вопрос закрывает статья аркана.
