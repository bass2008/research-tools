# Продукт глазами читателя

Сайт arcana-sense.ru: бесплатный расчёт матрицы судьбы по дате рождения (метод Наталии Ладини) и
платный полный разбор из двадцати разделов; совместимость пары по двум датам (`/compatibility`,
книга Юлианы Лисовской) с разделом «Совместимость в работе». Вокруг расчёта — энциклопедия:
страницы арканов, позиций, пересечений, хвостов, сочетаний, чакр, годов и арканов в совместимости.

## Расчёт: что текст не может нарушить

Предметный источник метода — `project/destiny-matrix/docs/archive/methodology.md`; поисковая фраза
формулу не переопределяет.

- Арканов 22. Сумма больше 22 сворачивается сложением цифр: 23 → 5, 1987 → 25 → 7. Арканов 23, 25,
  30 не бывает.
- Нумерация марсельская: 8 — Справедливость, 11 — Сила, 22 — Шут. У Уэйта 8 и 11 переставлены, а
  Шут — 0.
- Пол на числа не влияет: у мужчины и женщины, родившихся в один день, карта одна. Пол попадает
  только в название карты.
- Где какой аркан бывает и как часто — раздел «Где аркан бывает» в
  `tools/seo/prompt/arcanum-briefs/N.md` (считает `tools/seo/arcanum-brief.py` по движку сайта, все
  даты 1900–2026, оба пола). Самое частое, о чём спрашивают: в центре E не бывает 1, 2, 15, 17,
  19, 21; в духовной задаче B — только 1–12, это месяц рождения.

## Расчёт пары

- Точка пары — сумма одноимённых точек двух личных матриц, свёрнутая до 22. Единицы в паре не
  бывает; 13–22 получаются только из суммы ровно N (23–44 сворачиваются максимум в 12).
- Центр пары — атмосфера союза, а не личный центр: 15, 17, 19, 21 в центре пары бывают. Хвост пары
  читается M–N–D, первое число кратно трём; бывают хвосты, невозможные в личной карте («9 6 6»).
- «Совместимость в работе» — не сумма матриц, а сумма дат (день с днём, месяц с месяцем без
  ограничения 12, год с годом), на «дату» строится обычная матрица.
- Точки, их буквы у Лисовской и ключи корпуса — таблица в `prompts/pair-unit-prompt.md`; где какой
  аркан бывает в паре — точный перебор всех дат в `project/destiny-matrix/web/lib/pair/reachable.ts`.

## Схема: как называются точки

Так точки подписаны на сайте: на схеме, в разделах отчёта, на страницах позиций. Значков на нашей
схеме нет — ни сердца, ни доллара: только числа, буквы и подписи.

| Буква | Ключ | Подпись на сайте | Как ещё называют в поиске и в других школах |
|---|---|---|---|
| A | `day` | Портрет личности | визитка, визитная карточка, аркан дня рождения |
| B | `month` | Духовная задача | аркан месяца рождения |
| C | `year` | Материальная задача | аркан года рождения |
| D | `mission` | Кармическая задача | миссия |
| E | `center` | Центр карты · зона комфорта | центр, зона комфорта, середина. **Не «сердце»** |
| F, G | `father_line`, `mother_line` | Духовная мужская / женская линия рода | линия отца, линия матери |
| H, I | `descendants`, `inheritance` | Материальная мужская / женская линия рода | |
| J | `comfort_west` | Внутренняя левая точка | |
| K | `comfort_north` | Внутренняя точка таланта | |
| L | `comfort_east` | Вход денежной линии | вход денег |
| M | `comfort_south` | Вход отношений и хвоста | |
| N | `karmic_tail_middle` | Середина кармического хвоста | |
| O, P | `ajna_physics`, `ajna_energy` | Аджна, физика / энергия | |
| S, T | `anahata_physics`, `anahata_energy` | Анахата, физика / энергия | |
| R | `money_love_crossing` | Скрещение линий | |
| R1 | `love_middle` | Под сердцем | под сердцем, сердце, сердечко |
| R2 | `money_middle` | Середина денежной линии | под долларом, доллар — по чужим схемам, где у точки знак $ |

Подписи — `project/destiny-matrix/web/lib/i18n/dict/map.ts`, буквы — `web/lib/matrixMap.ts`.

## Страницы

| Тип | Адрес | Сколько | Источник текста и запросов |
|---|---|---:|---|
| Аркан | `/encyclopedia/arcanum/N` | 22 | `tools/seo/content/ru/arcana/N.json`, поле `article` |
| Позиция | `/encyclopedia/position/KEY` | 38 | `web/content/ru/positions.json` |
| Пересечение «позиция × аркан» | `/encyclopedia/position/KEY/N` | 74 | `web/content/ru/position-arcanum.json`, один `primary_query` |
| Кармический хвост | `/encyclopedia/karmic-tail/A-B-C` | 26 | `web/content/ru/karmic-tails.json` |
| Сочетание | `/encyclopedia/combination/A-B` | 231 | `web/content/ru/combinations.json` |
| Чакра | `/encyclopedia/chakra/KEY` | 7 | `web/content/ru/chakras.json` |
| Аркан на год | `/year/N` | 22 | `web/content/ru/year-arcana.json` |
| Аркан в совместимости | `/encyclopedia/compatibility/N` | 21 (2–22) | `tools/seo/content/ru/compatibility-arcana/N.json`; хаб — `category-hubs/compatibility.json` |
| Хабы категорий и концепт-хабы | `/encyclopedia/...`, корневые | 8 + 10 | `category-hubs.json`, `hubs.json` |

Пересечения есть не для всех пар: центр (16 арканов), отношения (16), под сердцем (20), деньги (11),
таланты (9), визитка (10 и 11). Точный список — `position-arcanum.json`.

Страницы года — самый посещаемый раздел. Их тексты ради других страниц не меняем.

## Кто владеет запросом

- Одна фраза — одна страница. Одни и те же слова в другом порядке или другой форме («22 аркана» и
  «22 аркан») — одна фраза.
- Узкая страница сильнее широкой: пересечение «позиция × аркан» сильнее страницы аркана и страницы
  позиции; «N на год» — страница года.
- Три числа — кармический хвост, два — сочетание, годы 19xx и 20xx — не арканы.
- «N в совместимости» — страница `/encyclopedia/compatibility/N`, а не аркан: на странице аркана
  раздел совместимости — абзац-два со ссылкой туда; «рассчитать», «онлайн» — калькулятор `/compatibility`.
- Статья ссылается на страницу-владельца и не спорит с ней; её главный запрос не ставит в заголовок
  своего раздела.
