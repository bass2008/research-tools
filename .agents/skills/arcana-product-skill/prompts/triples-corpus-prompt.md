## Как писать

Каждое толкование — та же структура, что у чакр:

- `heading` — заголовок 3–8 слов, суть сочетания. Без звёздочек. Заголовки в пакете не
  повторяются.
- `captions` — три подписи по 2–5 слов: что делает аркан именно в своей роли.
- `paragraphs` — три абзаца, всего {объём, обычно 150–220} слов:
  1. жизненная тема показателя и вклад каждого из трёх арканов;
  2. сочетание как готовая картина с повседневным проявлением; одну главную мысль можно выделить
     `**жирным**`;
  3. трудность из той же логики: возможный сценарий, а не диагноз характера.

Обращайся к читателю на «вы», пиши живо, конкретными действиями и ситуациями. Не склеивай три
словарных значения: подстановка других карт должна менять смысл. Повтор аркана — разные роли, а
не «удвоенное качество». Если в корпусе есть перестановки одних чисел по ролям — вывод у них разный.
Меняй вход и ритм от тройки к тройке: тексты пакета не начинаются одной формулой.

Нельзя: медицина и здоровье, обещания результата и дохода, прошлые жизни как факт, выдуманная
биография, перевёрнутые карты (у рассчитанного числа их нет), стереотипы по полу.

## Для заказчика: как завести новый корпус

1. Посчитать **все достижимые тройки** движком продукта на диапазоне дат, который принимает сайт.
   Набор, а не выборку по визитам или Вордстату: продукт должен ответить каждому.
2. Создать `tools/seo/{ключ}/` по образцу `tools/seo/energy-field/`: `packs.json` — тройки по 20
   на пакет; `check_pack.py` — копия проверки энергополя с этим набором и пределами объёма (она же
   прогоняет `text_policy`); `merge.py` — сборка пакетов в корпус продукта.
3. Сначала один пробный пакет с крайними случаями: повтор аркана, 22, 8 и 11, перестановки.
   Владелец одобряет подачу — затем остальные пакеты.
4. Писатели — по пакету на исполнителя, этим заданием с подстановками. Проверяющий — по
   правилам `seo-check-prompt.md` на выборке из каждого пакета.
5. Английская версия — отдельным переводом по готовому русскому корпусу.

**Модель и запуск.** Пакеты пишет Codex `gpt-6.1-sol` на `xhigh` (решение в `SKILL.md`, раздел
«Набор статей»). Один пакет — один запуск, не больше 5 одновременно; задание с подстановками —
в файле `<задание>.md`:

```bash
cd /home/sergey/Personal/research-tools
codex --ask-for-approval never exec --ephemeral --cd /home/sergey/Personal/research-tools \
  --model gpt-6.1-sol -c 'model_reasoning_effort="xhigh"' \
  -c 'mcp_servers.taskworker.enabled=false' -c 'mcp_servers.arcana-tasks.enabled=false' \
  --sandbox workspace-write --output-last-message <отчёт>.md - < <задание>.md > <лог>.log 2>&1
```

10 толкований на `xhigh` заняли около 12 минут. Запускать в фоне и смотреть лог раз в минуту.
