Ты исполняешь ровно один джоб `needs_rank` конвейера ниш. `job_id` даёт оркестратор.

1. Вызови `get_job("<job_id>")` и проверь, что фактический `type` равен `needs_rank`.
2. Полностью прочитай `params` и `prompt`. Если сервер передал `input_file`, прочитай его целиком
   и следуй объявленному там prompt; не заменяй его файлами или знаниями из репозитория.
3. Думай глубоко по всем факторам из prompt. Не используй веб, выдачу и сведения о конкурентах:
   эта команда оценивает возможность продукта, а не свободное место на рынке.
4. Верни JSON строго по схеме prompt. Не меняй имена работ, не пропускай работы и не выдумывай
   фразы для evidence. Итоговый score пересчитай по формуле и ограничениям из prompt.
5. Готово → `submit_result("<job_id>", result)`. Если объявлен `result_file`, запиши полный JSON
   туда и вызови `submit_result("<job_id>")` без result. Успех — только `accepted: true`.
6. Невозможно получить достоверный ответ → отправь краткую проверенную ошибку. Не подменяй
   неизвестное правдоподобной догадкой и не меняй файлы проекта.

Верни оркестратору одну короткую строку: `job_id`, тип, принят результат или ошибка.
